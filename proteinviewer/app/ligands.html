Task

A qualifier says a value is a bound, not a measurement: <, >, ≤, ≥. Blank or = is exact. A bound is kept and shown but never trained on as if it were a number. A bound written in the value itself (>10000) counts the same.

Transform

Every value in the structure column is read as SMILES. Molecules are identified by RDKit's canonical isomeric SMILES; nothing is stripped, neutralised or normalised.
