Set up the ligand dataset

    


    
    


    

    

      Task
      
      
    


    

      
      

        A qualifier says a value is a bound, not a measurement: <, >,
        ≤, ≥. Blank or = is exact. A bound is kept and shown but
        never trained on as if it were a number. A bound written in the value itself
        (>10000) counts the same.
      

      
      

        Transform
        
        
      

    


    

    
Every value in the structure column is read as SMILES.
      Molecules are identified by RDKit's canonical isomeric SMILES; nothing is stripped,
      neutralised or normalised.


    

    

    

      
      
      
    

  






  

    
Score poses

    


    

      Mode 
      

        Minimize in pocket is the one to use: the pose settles into the nearest
        low-energy position but stays inside a box around the pocket it was generated for.
        Rescore leaves the pose exactly as generated — generated poses often clash
        slightly, and then the number measures the clash rather than the fit.
        Minimize freely uses no box at all, so only the protein around the pose
        holds it in place and a pose can drift out of the pocket.
      

      
      
      
    


    
    

      Room added around the pocket's own alpha spheres, which the pocket run already wrote.
      4 Å fits most ligands; more room lets a pose drift further from the pocket.
    


    

      Pockets 
      

        Scoring runs over whole pockets, so this picks pockets rather than single rows.
        Visible groups only scores the pockets whose groups are showing — the same
        ones the table is listing when "Visible groups only" is ticked.
      

      
      
    


    
    

      How far minimization moved a pose. More than about 2 Å means the generated pose was
      strained and had to move to score well — that is a pose-quality signal, not a binding
      one. Marked in the RMSD column; it changes nothing about the run.
    


    
A score is a scoring function's value in kcal/mol, not a measured
      affinity and not a prediction of one. A large positive value means the pose clashes
      with the receptor.
